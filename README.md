# 雲程數位科技有限公司 官方網站

南台灣弱電整合工程與數位服務的單頁式靜態行銷網站。

- 技術構成：HTML5 + CSS + 原生 JavaScript
- 無框架、無建置流程、無套件相依
- 設計方向：日系文青／淺色極簡（`留白 > Typography > Grid > Photography > Color > Decoration`）

## 檔案結構

```
kaiyi-technology-website/
├── index.html              主頁面。所有文字內容集中於此
├── 404.html                錯誤頁。共用 styles.css，刻意不載入 app.js
├── styles.css              全站樣式。色彩與字體定義於檔首的 :root

├── robots.txt              ⚠ 內含 https://example.com 佔位網域
├── sitemap.xml             ⚠ 內含 https://example.com 佔位網域
├── images/
│   ├── hero.svg            首屏主視覺（佔位圖 1200×800）
│   ├── about.svg           關於我們（佔位圖 1000×750）
│   ├── work-01.svg         現場記錄 1（佔位圖 900×675）
│   ├── work-02.svg         現場記錄 2（佔位圖 900×600）
│   ├── work-03.svg         現場記錄 3（佔位圖 900×675）
│   ├── area.svg            服務地區（佔位圖 1000×700）
│   ├── favicon.svg         分頁圖示（向量）
│   ├── favicon-32.png      分頁圖示（32px）
│   ├── apple-touch-icon.png  iOS 主畫面圖示
│   ├── og-image.svg        社群分享縮圖（向量原稿）
│   └── og-image.png        社群分享縮圖（點陣版）
```

## 本機預覽

### 最簡單的方式

直接以瀏覽器開啟 `index.html`。多數內容可正常檢視。

### 以本機伺服器預覽（建議）

在專案根目錄執行下列任一指令：

```
python3 -m http.server 8000
```

或

```
npx serve .
```

然後以瀏覽器開啟終端機顯示的網址（通常為 `http://localhost:8000` 或 `http://localhost:3000`）。停止請按 `Ctrl + C`。

> 上述為一般常見做法，本檔撰寫時未在本專案環境實際執行驗證。實際可用指令依環境而定。

## 修改注意事項

- 修改前務必備份。
- 請使用純文字編輯器，並維持 UTF-8 編碼。
- **不要**修改 `class`、`id`、`data-` 屬性——會破壞樣式、錨點連結與 JavaScript 行為。
- 色彩集中定義於 `styles.css` 檔首的 `:root`，但部分色值直接寫死在檔案中，變更時需一併手動修改（清單見 `docs/04_維運交接手冊.md` 第 7-2 節）。
- 詳細作業方式見 `docs/04_維運交接手冊.md`。
