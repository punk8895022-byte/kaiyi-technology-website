### 3-1. 追加檔案的重要注意事項

目前的 `index.html` 的 `<head>` 中，**沒有** `<link rel="icon">`、**沒有** `<meta property="og:image">`、**沒有** `<link rel="canonical">`。因此：

- `images/favicon.svg` 即使加入版本庫，若未在 `index.html` 中加上對應的 `<link rel="icon" href="./images/favicon.svg">`，瀏覽器分頁圖示不會生效。
- `images/og-image.svg` 同理，若未加上 `<meta property="og:image" content="...">`（且值須為絕對網址），社群分享縮圖不會生效。此外，多數社群平台不支援 SVG 格式的 OG 圖片，實務上通常需要 PNG 或 JPEG。
- `sitemap.xml` 與 `robots.txt` 內需填入正式網域，正式網域為【需填寫】。

上述 `index.html` 的追加編輯**不在本文件撰寫者的作業範圍內**，請由負責該部分的成員處理，並於驗收前確認。
