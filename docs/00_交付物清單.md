### 1-1. 關於 `images/` 內的六個場景 SVG

指 `hero.svg`、`about.svg`、`work-01.svg`、`work-02.svg`、`work-03.svg`、`area.svg` 六個檔案（不含 favicon 與 og-image 等品牌識別資產）。

這六個檔案**不是實際案場照片**，而是以品牌色階製作的漸層色塊佔位圖（tonal placeholder），用途是在正式攝影素材到位前確認版面比例與色調。正式上線前必須全部替換為客戶自有照片，替換規格詳見 `04_維運交接手冊.md`。

`index.html` 中這六張圖的 `alt` 屬性目前皆為空字串（`alt=""`），即以裝飾性圖片處理。替換為具資訊價值的實際照片時，需一併補上替代文字。

## 3. 其他成員追加檔案的狀態與未解決事項

本文件初稿撰寫時，第 1 節編號 10–18 的檔案（`404.html`、`robots.txt`、`sitemap.xml`、圖示與 OG 資產、`tests/acceptance.mjs`）尚由其他成員平行作業中。**目前已確認全部存在於版本庫**，故已併入第 1 節的實存清單。

但下列事項**尚未解決**，驗收前必須處理。

### 3-1. `index.html` 已引用新追加的資產

`index.html` 的 `<head>` 已補上下列標籤，圖示與 OG 資產皆可正常生效：

- `<link rel="icon">`（SVG 與 32px PNG）、`<link rel="apple-touch-icon">`
- `<link rel="canonical">`、`<meta property="og:url">`
- `<meta property="og:image">`（指向 **PNG** 而非 SVG，因多數社群平台不支援 SVG）、`og:image:type`／`width`／`height`／`alt`、`og:site_name`
- Twitter Card（`summary_large_image`）四項
- JSON-LD 結構化資料（`LocalBusiness`）

`404.html` 亦已引用 favicon，兩頁行為一致。

### 3-2. 佔位網域尚未替換（重要）

`https://example.com` 為佔位網域，出現於下列**全部**位置，上線前必須一併替換為正式網域：

| 檔案 | 位置 |
| --- | --- |
| `robots.txt` | `Sitemap:` 行 |
| `sitemap.xml` | `<loc>` |
| `index.html` | `canonical`、`og:url`、`og:image`、`twitter:image` |
| `index.html` | `<head>` 末端 JSON-LD 的 `@id`／`url`／`logo`／`image` |

正式網域為【需填寫】。替換後請以全域搜尋確認已無 `example.com` 字串。

另外，JSON-LD 中的電話、電子郵件、地址、統一編號、營業時間**刻意留空未寫入**（填入佔位字串會被結構化資料檢測工具判為錯誤）。取得真實資料後請一併補上。

### 3-3. 自動化測試的執行環境

`tests/acceptance.mjs` 需要 Playwright（Chromium）。執行方式與檢查內容見 `03_測試規格書.md` 第 12 章。**本文件撰寫時尚未執行過**，因此不記載任何執行結果。
