## 撰寫原則（重要）

本組文件遵循下列原則。後續更新文件時，請一併遵守。

1. **不記載未經實測的數值。** 效能數值、Lighthouse 分數、瀏覽器相容性判定、無障礙符合等級，一律不得在未實測的狀態下記載。
2. **測試結果欄留空。** `03_測試規格書.md` 的「結果」與「執行日期」欄，在實際執行前一律留空並標示為 **未執行**。
3. **未知事實一律標示 【需填寫】。** 網域、聯絡方式、統一編號、上線日期、人員姓名、瀏覽器版本等未確定事項，皆以 `【需填寫】` 標示，不做推測性填寫。
4. **所有敘述可追溯至程式碼。** 色碼、字級、斷點等數值皆直接取自 `styles.css`／`index.html`，未經改寫。
