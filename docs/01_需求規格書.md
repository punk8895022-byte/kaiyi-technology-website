## 2. 網站目的

依頁面實際文案，本網站的目的可歸納為下列三點：

1. 說明雲程數位科技所承接的兩類服務（現場弱電整合工程、線上數位服務），並強調「同一個窗口負責」。
2. 說明服務流程與服務地區，讓潛在客戶在聯絡前即可判斷是否為可承接範圍。
3. 引導潛在客戶透過聯絡區段提出諮詢（主要行動呼籲為「預約現場勘查」／「預約勘查」）。

## 6. 功能需求

| 編號 | 功能 | 實作內容（依 `app.js` / `styles.css`） |
| --- | --- | --- |
| F-01 | 頁首固定顯示 | 頁首 `position: fixed`，恆常顯示於畫面上方。 |
| F-02 | 頁首捲動狀態變化 | 垂直捲動量超過 16px 時，頁首加上 `is-scrolled`，背景不透明度由 0.82 提高為 0.95 並顯示下框線。 |
| F-03 | 錨點平滑捲動 | 以 CSS `scroll-behavior: smooth` 實作。並以 `scroll-padding-top`（頁首高度 + 24px）避免標題被固定頁首遮蔽。 |
| F-04 | 導覽列現在位置高亮 | 以 `IntersectionObserver`（`rootMargin: -45% 0px -50% 0px`）判定，對應區段進入判定範圍時，桌機導覽列該連結加上 `is-active`（顯示底線）。 |
| F-05 | 行動版抽屜選單開關 | 點擊漢堡鈕切換開闔；`aria-expanded` 與 `aria-label`（開啟選單／關閉選單）同步更新；漢堡圖示變形為叉號。 |
| F-06 | 抽屜選單自動關閉 | (a) 點擊抽屜內任一連結後關閉；(b) 按下 Escape 鍵關閉並將焦點移回漢堡鈕；(c) 視窗寬度大於 940px 時關閉。 |
| F-07 | 捲動淡入 | 具 `.reveal` 類別的元素（服務卡片 10 張、現場記錄 3 則、流程 5 步、服務地區圖）進入判定範圍（`threshold: 0.12`＋`rootMargin: 0px 0px -8% 0px`）時加上 `is-visible`，淡入並上移歸位。觸發後即停止觀察（僅執行一次）。**隱藏狀態僅在 `<html>` 具有 `js` 類別時生效**（由 `<head>` 內的行內 script 加上），因此 JavaScript 失效時內容維持可見。不支援 `IntersectionObserver` 的環境會直接全部顯示。 |
| F-08 | 淡入時間差 | 依 DOM 順序給予 `index × 40ms` 的延遲，上限 160ms。 |
| F-09 | 頁尾年份自動更新 | 以 `new Date().getFullYear()` 覆寫 `[data-year]` 的內容。 |
| F-10 | 聯絡表單前端示範 | 送出時阻擋預設行為，於 `.form-status`（`role="status"`、`aria-live="polite"`）顯示「已收到您填寫的內容。此為前端示範，尚未實際送出。」按鈕不停用、焦點不移動。**不會實際送出任何資料。** |
| F-11 | 略過至主要內容 | 鍵盤 Tab 聚焦時顯示「跳至主要內容」連結，連至 `#main`。 |
| F-12 | 減少動態偏好對應 | 作業系統設定為減少動態時，全站轉場／動畫縮短為 0.01ms、延遲歸零，`.reveal` 直接以最終狀態顯示。 |
| F-13 | 表單必填驗證 | 姓名/公司、聯絡方式、問題描述三欄設有 `required`。表單未指定 `novalidate`，故未填時由瀏覽器原生驗證阻擋送出。 |
| F-14 | 鍵盤聚焦外框 | 全站共通的 `:focus-visible` 外框（3px 實線、`--text` 色、外偏移 2px）。滑鼠點擊時不顯示。 |
| F-15 | 圖片延遲載入 | 首屏主視覺為 `fetchpriority="high"`；其餘五張為 `loading="lazy"`。全部 `decoding="async"`。 |
| F-16 | 結構化資料 | `<head>` 內含 JSON-LD（`LocalBusiness`），涵蓋公司名稱、服務地區四地、兩個服務群組共 10 項服務。電話、電子郵件、地址、統一編號、營業時間**刻意未寫入**（填入佔位字串會被檢測工具判為錯誤）。 |
